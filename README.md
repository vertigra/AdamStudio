# AdamStudio

### 

 * Сервис настроек сохраняет настройки при их изменении через подписку в персистент сервис вызыввается сэйв
   это позволяет избежать повторного сохранения при загрузке.
 * Восстановление настроек должно происходить из персистент сервиса, в свою очередь, ISettingManager 
   обеспечивает их актуальность на момент обращения
 * Тулбоксы не должны дублировать функционал главного меню, технически это работает, но возможны баги.
   Если обычное менюсмотриться неинтересно, то возможно стоит прикрутить выдвигающееся боковое аля винбокс,
   но это нужно делать в MainView через например экспанедер
